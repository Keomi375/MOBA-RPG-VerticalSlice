# 🛡️ MOBA-RPG-VerticalSlice

## 🎮 О проекте
Вертикальный срез (Vertical Slice) гибридного проекта на стыке жанров **MOBA** и **Action-RPG**. Проект разрабатывается в рамках практической программы создания игр.

## 🛠 Технологический стек
- **Игровой движок:** Unity (URP)
- **3D-моделирование:** Blender
- **Контроль версий:** Git + Git LFS

## 🎯 Объем вертикального среза (Scope)
- **Игрок:** 1 управляемый герой с 3 уникальными способностями.
- **Враги:** 2 типа рядовых противников + 1 босс.
- **Локация:** 1 арена с объектами окружения.
- **Core Loop:** Исследование → Бой → Накопление энергии/опыта → Битва с боссом.
